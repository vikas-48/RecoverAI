# RecoverAI Synthetic Dataset

Generated with random seed 42 for reproducibility.

## Files
- customers.csv: 4,000 synthetic customers
- payments.csv: 20,000 failed payment events
- recovery_cases.csv: labelled recovery dataset used for model training/evaluation

## Important
The recovery labels and outcomes are synthetic ground truth designed to create realistic behavioral patterns for a hackathon prototype. They are not real Razorpay/customer data.

## Splits
- train: 70%
- validation: 15%
- test: 15%
